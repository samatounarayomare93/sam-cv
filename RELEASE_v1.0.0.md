## 🚀 DEPLOYMENT PATHS

### Option 1: Local Development (5 minutes)
```bash
git clone https://github.com/Sam-Cordahi/Sam_Job_Automator.git
cd Sam_Job_Automator
python -m venv .venv
source .venv/bin/activate  # or .venv\Scripts\activate on Windows
pip install -r requirements.txt
cp .env.example .env
# Edit .env with credentials
python run.py
```

### Option 2: Cloud Deployment (10 minutes)
1. Create Render.com service
2. Connect GitHub repository
3. Set environment variables (see DEPLOYMENT_SECRETS_GUIDE.md)
4. Deploy and verify
