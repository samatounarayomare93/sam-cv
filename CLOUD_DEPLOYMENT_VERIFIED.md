## 🔧 TROUBLESHOOTING

### Problem: Bot Not Starting
**Solution:**
1. Check Render logs
2. Verify all environment variables are set
3. Check Supabase connection
4. Restart service manually

### Problem: Emails Not Sending
**Solution:**
1. Check SMTP credentials in Render
2. Verify email provider limits not exceeded
3. Test with /test_strike in Telegram
4. Check Render logs for errors

### Problem: Telegram Not Responding
**Solution:**
1. Verify TELEGRAM_BOT_TOKEN is correct
2. Verify TELEGRAM_CHAT_ID is correct
3. Send /start to bot
4. Check Render logs

### Problem: Database Errors
**Solution:**
1. Verify SUPABASE_URL is correct
2. Verify SUPABASE_KEY is correct
3. Check Supabase dashboard for connection
4. Restart Render service
