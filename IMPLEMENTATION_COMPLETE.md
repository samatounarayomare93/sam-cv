## 🔧 TROUBLESHOOTING

### Issue: Bot not starting
**Solution:**
1. Check Render logs for errors
2. Verify all environment variables are set
3. Check database connection
4. Verify Telegram token

### Issue: No health reports
**Solution:**
1. Check Telegram chat ID is correct
2. Verify bot token is valid
3. Check Render logs for errors
4. Restart the bot

### Issue: High memory usage
**Solution:**
1. Check resource monitor logs
2. Verify garbage collection is running
3. Check for memory leaks
4. Restart if needed (auto-restart will handle it)

### Issue: No applications sent
**Solution:**
1. Check email providers are configured
2. Verify AI is working (or fallback templates)
3. Check database for leads
4. Check circuit breaker states
