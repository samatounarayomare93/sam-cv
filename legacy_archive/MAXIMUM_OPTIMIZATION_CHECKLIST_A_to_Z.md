## A. 性能优化 (Performance Optimizations)

### A1. 爬虫性能提升
- [ ] **A1.1** 减少爬虫sleep时间：从 `random.uniform(2.0, 4.0)` 优化到 `random.uniform(1.0, 2.0)`

- [ ] **A1.5** 添加请求压缩：启用 gzip/deflate 压缩减少带宽

- [ ] **A2.3** 添加批量发送模式：支持一次连接发送多封邮件
- [ ] **A2.4** 优化邮件大小：压缩HTML内容，移除冗余CSS
- [ ] **A2.5** 实现快速失败机制：超时不等待直接切换provider

### A3. AI处理优化
- [ ] **A3.1** 添加请求缓存：相同job posting 24小时内只分析一次
- [ ] **A3.2** 实现批量分析：一次API调用分析多个job
- [ ] **A3.3** 优化prompt长度：截断到3000 chars避免超限
- [ ] **A3.4** 添加结果缓存：Redis或本地LRU缓存
- [ ] **A3.5** 实现异步AI调用：不阻塞主流程

### A4. 数据库查询优化
- [ ] **A4.1** 添加索引：company_name, job_title, job_url
- [ ] **A4.2** 批量插入：改 `insert()` 为批量 `upsert_many()`
- [ ] **A4.3** 实现本地缓存：减少数据库往返
- [ ] **A4.4** 查询超时优化：当前8秒太长，改为3秒
- [ ] **A4.5** 添加查询日志：识别慢查询

### A5. 内存优化
- [ ] **A5.1** 实现对象池复用：减少GC压力
- [ ] **A5.2** 流式处理大文件：PDF等大文件不一次性加载
