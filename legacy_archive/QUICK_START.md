# Quick Start

Open these files in this order:

## 1) `LAUNCH_KIT_INDEX.md`
This is the master map for everything launch-related.

## 2) `ULTRA_SHORT_LAUNCH.md`
This is the fastest go/no-go checklist.

## 3) `PRE_LAUNCH_TEST.ps1`
Run this PowerShell script to verify Python, dependencies, config, and the test email path.

## If you prefer the batch version
Use `PRE_LAUNCH_TEST.bat` instead of the PowerShell script.

## After that
- Review `GITHUB_ISSUE_CHECKLIST.md`
- Review `README_LAUNCH_SECTION.md`
- Use `LAUNCH_NOTE.txt` for daily tracking
