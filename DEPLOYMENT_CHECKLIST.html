1️⃣ افتح Render.com
اضغط على الزر بالأسفل لفتح Render.com بالمتصفح

🌐 افتح Render.com
2️⃣ سجل دخول بـ GitHub
• اضغط Sign In أو Get Started
• اختار Continue with GitHub
• وافق على الصلاحيات
3️⃣ اعمل Web Service جديد
• اضغط الزر الأزرق New + (فوق يمين)
• اختار Web Service
4️⃣ اختار Repository
• دور على: Sam_Job_Automator أو sam-cv
• اضغط Connect
5️⃣ املأ المعلومات
انسخ هالقيم بالضبط:

• Name: sam-job-automator
• Region: Frankfurt
• Build Command: pip install -r requirements.txt
• Start Command: python run.py
• Instance Type: Free
6️⃣ ضيف Environment Variables
• لف تحت لقسم Environment Variables
• اضغط Add from .env
• افتح ملف render_env_vars.txt
• انسخ كل شي والصقه
• اضغط Add
7️⃣ انشر!
• اضغط الزر الأزرق الكبير: Create Web Service
• استنى 2-3 دقائق (بتشوف logs تتحرك)
• لما تشوف Live بأخضر → نجح! ✅
8️⃣ اختبر البوت
• افتح Telegram
• دور على: @samcvbot
• ابعت: /start
• إذا رد عليك → ✅ نجح!
